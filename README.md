# CODZ-Compiler
CODZ Compiler is a web-based online coding platform supporting C, C++, Java, and Python. It provides code execution, error detection, AI-powered debugging, project management, and source-code download. Built with React.js, Node.js, Express.js, and MongoDB, the platform is containerized and deployed using Docker.
A major feature of CODZ Compiler is its AI-powered code assistance system. The AI module analyzes the user's source code and error messages to identify potential bugs, explain the cause of errors in simple language, and provide appropriate suggestions for fixing them. This makes the platform particularly useful for students and beginners who may have difficulty understanding traditional compiler error messages.
CODZ Compiler also includes project and file management functionality, allowing users to create, organize, and manage source-code files within different projects. Users can download their project source code whenever required, making it convenient to continue development locally or share their work.
The system follows a client-server architecture. The frontend provides the interactive coding interface, while the backend manages API requests, code execution, project operations, and communication with the AI module. The application is developed using technologies such as React.js, JavaScript, Node.js, Express.js, and MongoDB. For reliable and consistent deployment, the application is containerized using Docker, allowing the frontend, backend, and required services to be configured and deployed in isolated containers.
Overall, CODZ Compiler aims to provide a fast, accessible, beginner-friendly, and intelligent coding environment by combining online code execution, AI-assisted debugging, project management, and Docker-based deployment in a single platform.
